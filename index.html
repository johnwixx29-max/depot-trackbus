How it works

A small GPS tracker on each bus, and a server that only trusts devices it knows.

  1. Tracker on the bus

    A GPS device sends the bus's position every few seconds over the mobile network.

  2. Server checks it

    The server confirms the device is registered and the position makes sense, then saves it.

  3. Live database

    One shared database holds buses, routes, timetables and positions, and pushes changes out instantly.

  4. App and dashboard

    Riders and depot staff see the same data, so nobody has to phone anybody to find out.
